## Changes since 0.4.45

Production 2026-11-27: 22 `v2-instance-*` hosts never completed an inventory. With 0.4.45 their heartbeat showed each capture in `collect:provenance` and the agent's PID changed every minute: the agent restarted mid-verification. All 22 have 961 MB of RAM and run at about 84% memory, against 1.7 GB and 50% on healthy hosts. Origin verification read every package index whole: `trustedRead` loaded the file (up to 128 MiB) only to check its ownership, then `apt-helper cat-file` loaded the decompressed index again before parsing it. On these hosts the kernel's OOM killer ended the agent.

- **Indexes are streamed.** The ownership check no longer reads the file (`trustedFile`), and `apt-helper cat-file` output is hashed, counted and parsed as it streams, keeping only in-scope stanzas. As before, the entries count only when the streamed size and SHA-256 equal the signed values. Memory per index drops from the whole index to one stanza plus the kept entries.
- **Low-memory backstop.** Verification is skipped when `/proc/meminfo` reports less than 128 MiB `MemAvailable` (`verification_skipped_low_memory`); the packages upload with unknown origins.
- The monitoring heartbeat interval and every other loop are unchanged.
